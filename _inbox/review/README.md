# _inbox/review/ — Batch Review Pile

This folder holds Tier 3 memory items — low confidence, INFERENCE-sourced, or UNVERIFIED items that do not need immediate attention but should not be discarded.

**Review these weekly** using the batch review prompt in PROMPTS.md Part 3.

**Items land here when:**
- `confidence: low`
- `source_type: INFERENCE`
- Flagged UNVERIFIED
- Episodic compression candidates

**Do not load these files into working memory.** They are unvalidated.
